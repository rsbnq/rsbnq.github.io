Gallery photos live in this folder, one sub-folder per section of the Gallery page.

- Folder names become section headings: "02-stages" shows as "Stages".
- File names become captions: "01-wedding-stage-with-flowers.jpg" shows as "Wedding stage with flowers".
- The numbers at the start set the order and are not shown.
- Photos straight from a phone are fine; they are resized automatically when the site builds.
- Avoid photos where guests' faces or couples' names are clearly visible.
- To add a new section, create a new numbered folder, e.g. "07-birthday-parties".
